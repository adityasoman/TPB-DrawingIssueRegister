1. Upload Transmittal(s)

Drag & drop transmittal files here or click to browse

    Accepts one or more .xlsx, .xls, or .csv transmittal files.

    2. Issue Mode

    Choose "Single issue" if this transmittal covers one drawing issue, or "Multiple issues" if it bundles several into one file.

    3. Load Template

    A "DIR_Template" sheet already exists in this workbook. Insert another copy?

    Inserts the standard TP Bennett drawing issue register template as a new sheet in this workbook.

    4. Populate Register

    Reads the uploaded transmittal(s) and fills in the issue register.
