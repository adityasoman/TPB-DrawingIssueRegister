# Branding assets

Drop the TP Bennett logo here as **`logo.png`** (this exact filename — transparent PNG recommended, roughly 32px tall / proportional width works best in the header bar).

Once the file exists at `src/assets/branding/logo.png`, it's picked up automatically on the next build/dev-server reload — no code changes needed. Until then, the task pane header shows a "TP BENNETT" text fallback instead of a broken image.
